# Python OOP Basics

## Project Overview

This repository contains beginner-friendly Object-Oriented Programming (OOP) examples in Python.

The project demonstrates the core concepts of OOP, including Classes, Objects, Constructors, Attributes, Methods, and the use of `self`.

These examples were built as part of my Data Science and Machine Learning learning journey.

---

## Topics Covered

### Classes

```python
class Student:
```

Blueprint used to create student objects.

### Objects

```python
student1 = Student("Jaydeep")
```

Represents a real-world student.

### Constructor

```python
def __init__(self):
```

Automatically initializes object data.

### Self Keyword

```python
self.name = name
```

Used to store and access object attributes.

### Methods

```python
def greet(self):
```

Functions inside a class.
